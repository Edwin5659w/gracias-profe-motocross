# Gracias, Profe 🏁

Página de agradecimiento con temática de motocross y programación (HTML, CSS y JS puro).

## Personalizar
Abre `script.js` y cambia el bloque `CONFIG` del inicio:
- `profesor`: nombre del profe (ej: "Profe Carlos")
- `de`: nombre de quien regala
- `mensaje`: el mensaje final

## Desplegar en Vercel
1. Sube esta carpeta a un repositorio de GitHub (o usa `npx vercel` dentro de la carpeta).
2. En vercel.com → Add New → Project → importa el repo.
3. Nombre del proyecto: **gracias-profe-motocross** (así la URL queda https://gracias-profe-motocross.vercel.app, que es la del QR).
4. Framework Preset: **Other**. Deploy.
